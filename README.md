# Portfolio

My personal portfolio and freelance services site, live at [joshiii7.github.io/portfolio](https://joshiii7.github.io/portfolio/). It's a static site: no framework, just HTML, Sass, and vanilla JS.

## Contents

- `index.html`, `about.html`, `contact.html`, `pricing.html` - main pages
- `projects/` - case studies for client work (ASCB attendance and payroll, Bislig City BPLS, Bislig City car rental, MIS grading system, S.H. Mercantile inventory)
- `services/` - service pages (business websites, custom software, frontend development, maintenance and SEO)
- `css/style.scss` - Sass source, compiled to `css/style.css`
- `js/` - page scripts and the JSON data behind the projects, services, and skills sections

## Running it

Open `index.html` in a browser, or serve the folder with any static file server. Deploys automatically via the GitHub Actions workflow in `.github/workflows/static.yml`.
